# Designing Professional Learning Experiences



## Overview



An instructional design approach for transforming complex professional knowledge into structured learning experiences that support capability development.



## Focus Areas



- Instructional Design

- Learning Experience Design

- Curriculum Architecture

- Learning Content Development

- Assessment Alignment



## Approach



The learning design model connects:



Concept → Practice → Application → Demonstration



to help learners move from knowledge acquisition to practical capability.



## Value



This approach supports:



- clearer learning journeys

- meaningful practice opportunities

- assessment alignment

- workplace application
